# SysLoop

Prywatny trenażer systemu licytacyjnego. Specyfikacja: [docs/SPEC.md](docs/SPEC.md).

Node 24, npm 11. Instalacja: `npm install`. Serwer: `npm run dev` (port 5175).
Kontrole: `npm run lint`, `npm run build`, `npm test`.

Pliki PDF, wyniki importu i klucze pozostają lokalne. Aplikacja nie zawiera danych systemu.
Aplikacja: [system.bridgeloop.pl](https://system.bridgeloop.pl).
